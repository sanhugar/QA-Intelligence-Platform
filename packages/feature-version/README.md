# `@ati/feature-version`

Feature Version & Lineage primitives (WP-3.3).

Nest-free deterministic identity/version/lineage metadata from terminal intake + `ClassificationResult`.

## Non-responsibilities

- AI / ML / LLM
- Persistence
- Parsers
- Intake / classification / workflow orchestration
- ARS product, HITL, generation gating
- Domain Feature Version product lifecycle

## Public API

Import only from `@ati/feature-version` (`src/index.ts`).
