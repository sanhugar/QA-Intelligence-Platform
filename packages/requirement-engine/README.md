# `@ati/requirement-engine`

Requirement Intelligence Engine Foundation (WP-2.5).

Nest-free structural substrate: technology-neutral requirement model, pipeline **ports**, engine lifecycle, and in-memory registration.

## Non-responsibilities

- Real format parsers (Markdown/FDD/PRD/User Story)
- LLM / AI / embeddings
- Knowledge Intake / ARS designation (WP-3.1 / ADR 0011)
- Persistence

## Public API

Import only from `@ati/requirement-engine` (`src/index.ts`).
